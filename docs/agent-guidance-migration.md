# Agent guidance

[AGENTS.md](../AGENTS.md) owns repository-wide development rules.
[Component architecture](developer/component-architecture.md) describes the
implementation layers, public contracts, host responsibilities and validation.

SGUI contains reusable UI. Hosts supply routing, account operations, application
data, translation policy and persistence. Repository examples and test fixtures
remain independent of application services. Third-party code retains its licenses
and attribution obligations. The [owner decisions](developer/owner-decisions.md)
record first-party rights and current delivery choices.
