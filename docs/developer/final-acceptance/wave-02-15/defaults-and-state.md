# Default/state reconciliation supplement

Source references are relative to packages/ui/src. This supplements parallel-01/04, not a claim of exhaustive historical upstream compatibility. `public-contract-index.json` indexes every saved public symbol/alias route and the captured owned visual/state/naming/composition props. It explicitly marks source changes. The 678 saved fallback candidates comprise 213 destructuring defaults, 31 parameter defaults and 434 nullish fallbacks; the last group includes internal logic and cannot all be published as prop defaults. This classification prevents accidental API promises from private expressions.

### Historical compatibility deltas added in this wave

`local-extraction-reference.json` preserves six exact local initial-extraction files at `21adebd61bedfc6a1ed395fe664ff4be83896821`. These are SGUI Git objects, not an upstream checkout or native run. Along with parallel-01's twelve retained source contracts, they form a bounded historical closure:

- Original usePersistentState(key, initialValue) automatically used localStorage/raw JSON. Current same-shaped calls are memory-only unless storage is explicitly selected. Existing persistence/event assumptions require migration even though basic calls compile. The current optional envelope/validate/migrate and browser fallback are additions; raw unversioned JSON remains possible. Migration guidance already describes the opt-in change.
- Pagination still uses page/pageSize, but valid positive custom sizes are no longer inherently capped by menu suggestions. New options govern normalization; omitted options must not be interpreted as 25/50/100-only policy.
- Original preset modules embedded English data arrays. Current compatibility arrays coexist with fresh translated Course factories and canonical status metadata. Data identifiers stay class-compatible where required; new factories are additive, not blanket deprecations.
- Original ImageNode version=1 fields already included src/altText/width/height/assetId/assetVersionId. Current serializer preserves this public metadata and default nulls; replacing visual renderer with owned elements is not by itself a saved-schema break. Current address policy can reject displaying unsafe addresses previously rendered; that is an observable security/behavior policy difference, not a schema-field removal.
- Original editorConfig registered its supported rich nodes. Current config extends the restored set and uses an owned Link replacement while serializing public `link`; preserving ImageNode fields alone does not prove arbitrary document equivalence. Host document round-trip tests and open editor V leaves retain their own limits.

Remaining A-B-05 deliverable: normalize every public symbol's indirect defaults and compare complete inherited original upstream contracts at their locked historical versions. Do not label all 469 contracts historically compatible from this bounded closure. This wave added the complete projection index, classified candidate kinds, shared-family table and six historical references; it did not reconstruct the retired dependency graph.
