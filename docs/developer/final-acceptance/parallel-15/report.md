### Locale and date behavior

- `i18n/index.tsx`: translation adapter supplies locale, `t(key,{defaultMessage,namespace,values})`, useNamespace. Default adapter formats English ICU with en-US. Host errors, key echoes, nonstring values and missing-translation sentinels fall back to defaultMessage. No catalog fetching or host logging policy is owned by SGUI; `icu.ts` owns fallback formatting and variable tools. Preset factories accept the host translator and must be recreated on locale change.
- Calendar/date/time components use React Aria locale through the owned Provider. `experimental/Provider/Provider.tsx` reads the host translation adapter locale and supplies I18nProvider plus scope lang/direction, so the adapter is the locale authority when using Provider. A bare ThemeScope alone does not establish that bridge. `DateRangeSelector/date-contract.ts` defines Gregorian `YYYY-MM-DD` civil dates, inclusive ordered ranges, inclusive days versus nights, bounds and endpoint/interior availability. `dateTimeToInstant` requires explicit timezone and rejects DST gap/overlap ambiguity by default, with earlier/later override. No implicit server timezone conversion is promised.
- `DateField/parseDateText.ts`: no Date.parse/rollover; ISO/compact ISO, locale-order numeric forms, localized digits, locale/English named months, fixed two-digit-year window 1950–2049, relative grammar from `utils/relative-dates.ts` with explicit reference date. Formatted dates use Gregorian UTC civil math. Time text accepts HMM/HHMM and a/p suffix, strict hour/minute ranges, explicit hour-cycle display and availability/bounds. Date/time validation is live natively but visible errors defer to commit/blur/native invalid, except host invalid.
- `utils/formatDueDateLabel.ts`: defaults en-US; invalid/unsupported locale falls back en-US. Accepts Date/string/number using native Date parsing (distinct from civil field grammar); invalid due date yields translated “Due date unavailable.” Relative labels use local day boundaries and time differences; no explicit timezone option. Invalid now falls back to current time. `LearnerClassCard/formatDueDateLabel.ts` reexports it.
- `AppDataGrid/ownedGridCells.tsx`: date-only strings preserve date via UTC; dateTime accepts Date, finite epoch or timezone-qualified ISO string, rejects rollover/invalid input. Host locale/timeZone/custom formatter are explicit; invalid Intl config/formatter errors yield the fallback (“—”). Display formatting is separate from raw sort/filter values.

Source/test references: date-contract and DateContracts.next100 tests; DateField parseDateText/parseRelativeDateText/TextDateField tests; TimeField parseTimeText/TextTimeField tests; utils relative-dates/formatDueDateLabel tests; i18n index/icu/ICUFormatting regression tests; ownedGridCells tests. Actual browser locale, IME, device and spoken-AT behavior remain separately open.
