# Actual zoom evidence to complete A-D-09

Prepared procedure; **not executed**. Keep this record separate from accepted HB19/HB20 root-text enlargement and CSS viewport reflow. Use a coordinator-admitted frozen candidate and a real browser with its built-in page Zoom controls. Do not change CSS zoom, transform, device pixel ratio or root font size to stand in for this operation.

1. Save candidate commit, relevant source and compiled stylesheet/fixture hashes, OS, browser/version, window dimensions, font settings and starting zoom. Retain a browser-chrome screenshot showing the actual zoom setting. Confirm 100%, then use browser controls to select 200% and 400% on the same fixed desktop window.
2. At each zoom inspect a long-title ClassCardFrame, independent AppShell main/navigation panes, and open multi-section AppModal. Follow native Tab/Shift+Tab through all visible dialog controls; open a tab menu, resize while open, then Escape. Record focused accessible name, viewport/control/clipping-ancestor rectangles, ring visibility, footer reachability, native scrolling and restoration target. Scroll to reveal content rather than requiring simultaneous fit. Do not weaken assertions to permit obscured focus.
3. Repeat one long-label English and Arabic/RTL slice at each density. Test the prescribed spacing changes (line height1.5, letter spacing .12em, word spacing .16em, paragraph spacing2em) separately and combined. Use a font override whose first named family is deliberately unavailable, followed by system sans; separately substitute a serif and monospace face. Record resolved fonts and spacing, without modifying production source. Override stress must preserve the component token/background scope.
4. Record each configuration once with screenshots and exact observations; retain individual passes when a different configuration fails. A result must say whether there was lost content, bidirectional overflow, clipped labels/rings, hidden actions or loss of state. Give failures bounded reproduction steps and route/fixture IDs.
5. Restore zoom/font/spacing to the initial settings. Leave the user's existing browser/session and server3000 untouched; create a disposable review session.

Suggested machine record fields: `candidate`, `sourceHashes`, `outputHashes`, `os`, `browser`, `browserVersion`, `zoomUI`, `viewport`, `fixture`, `theme`, `density`, `direction`, `fontStack`, `resolvedFont`, `spacing`, `focusedName`, `controlRect`, `clippingRects`, `restoredFocus`, `screenshot`, `result`, `reviewer`, `limitations`. Never prefill pass, speech or human approval. This procedure does not replace physical touch or spoken assistive-technology evidence.
