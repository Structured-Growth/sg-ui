# Docs native-fixture migration ledger

## Scope and evidence boundaries

DOCS-005 replaces the legacy example host with the docs-owned static React fixture host alongside the Next.js website. This inventory was captured before editing browser routes on 2026-10-14. It records all **102 existing browser spec files**, their **164 referenced fixture IDs**, and **75 original scenario modules**. The route/host migration does not close new functionality, regression, browser, visual, device or assistive-technology acceptance gates.

The original Storybook static index supplied exact IDs, export names and source module paths. Static IDs and finite template choices in the existing specs were reconciled against that index; no wildcard-only match is treated as a required fixture. Original IDs are retained as fixture identities. The existing suite now uses `/fixtures/?id=<id>` with its applicable `args`, `globals` and explicit play preference. Host setup changes are recorded independently from the assertions and historical acceptance evidence.

Current execution evidence is in the [retirement receipt](docs-website.md#storybook-retirement-receipt--2026-10-14): the complete initial three-engine run and bounded corrections of all 14 failures are recorded separately, followed by eight passing public docs checks. The new Select sizing spec supplements the 102 original specs; it does not alter this historical inventory or acceptance counts.

Original module paths below are provenance, not current import instructions. Each maps to an ordinary docs-owned fixture module. Historical batch numbers, acceptance identifiers, test titles and evidence receipts remain authoritative in their original records; this ledger does not rename, retest or reconfirm them. References below point to evidence documents that explicitly mention a spec; the absence of a direct filename reference does not imply a lack of historical evidence.
